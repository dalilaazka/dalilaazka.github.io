# Azka Khaira Dalila Urfa — Geospatial Portfolio

## Publish with GitHub Pages
1. Open the repository `dalilaazka/dalilaazka.github.io`.
2. Upload `index.html` and `style.css` to the repository root (same level as README.md).
3. Commit the changes to the `main` branch.
4. In Settings → Pages, confirm Source is `Deploy from a branch`, Branch is `main`, Folder is `/(root)`.
5. Visit https://dalilaazka.github.io/ after the deployment finishes.

## Before publishing
- In `index.html`, replace `YOUR_EMAIL@example.com` with the email address you want to publish.
- Add your LinkedIn profile URL when ready.
- Review all project summaries and make sure they accurately reflect work you are allowed to disclose.
- Keep confidential client/company data out of the public repository.

The page uses Google Fonts via an external stylesheet. If the fonts cannot load, it falls back to system fonts.
